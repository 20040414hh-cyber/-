# 17 词云型信息图形（Word Cloud）

> **类型说明**：词云型信息图形以词语或短文本作为基本视觉单元，通过空间聚集、字号、字重、颜色、方向与轮廓组织文本信息。它属于可视化文本的具体表现形式。本条为用户补充类型，**不属于原课件第22–38页列出的16种课件类型**。

## 与可视化文本型的关系

- **11 可视化文本型（Visualized Text）**是较宽泛的表现类型，涵盖文字列表、语义关系组织、文字路径与文字图形化等形式。
- **17 词云型（Word Cloud）**聚焦于词项在有限画面中的聚集与分布；常见做法是将词频或其他权重映射为字号，但并非所有外观类似词云的文字构形都具有统计含义。
- 若文字只是沿轮廓或路径进行装饰性排布，而没有词项统计或权重映射，应准确称为“词云式文字构形”，不要直接宣称它呈现了词频。

## A. 数据逻辑与最小结构

词云的基本信息单元可表示为：

`词项｜频次/权重｜语义类别（可选）｜来源与说明`

典型处理流程：

1. 确定文本语料与统计范围。
2. 分词或提取词项，统一大小写、词形及同义表达。
3. 清理停用词、无意义符号和重复项，并记录清洗规则。
4. 统计词频，或计算明确说明的其他权重。
5. 选择展示词项及权重范围，生成布局。

若没有原始语料、词频或权重数据，只能分析文字的视觉组织，不能将字号差异解释为统计差异。

## B. 借用的统计图形与计算方式

- **词频统计**：对清洗后的语料计算词项出现次数。若使用相对频率，应说明分母和统计范围。
- **权重计算**：如采用 TF-IDF、主题权重或人工评分，应明确指标定义、计算方式和数据来源，不与原始词频混为一谈。
- **字号映射**：可将频次或权重映射到字号区间，但应设置最小与最大字号，避免极端值压缩其他词项的可读性。
- **尺寸边界**：排版软件可能对字号进行缩放、旋转和避碰；最终占据面积不一定与原始频次成正比。

没有图例、数据表或制作说明时，不从单个词语的视觉大小反推具体数量。

## C. 视觉编码（点、线、面、体、符号、色彩与排版）

| 视觉变量 | 常见作用 | 使用时需要说明 |
| --- | --- | --- |
| 字号／字重 | 表示词频或权重，也可用于标题层级 | 是否绑定数值、映射范围与缩放规则 |
| 颜色 | 区分语义类别、主题或来源 | 颜色与类别的对应关系 |
| 位置／方向 | 组织版面、形成视觉节奏 | 是否有语义或数据含义；装饰性布局应明确标注 |
| 轮廓／形状 | 形成整体主题意象 | 轮廓是装饰还是承载分类信息 |
| 字距／密度 | 调整聚集程度与可读性 | 不把排版密度直接当作频率 |

应优先保证词语可辨认、层级清楚和色彩对比适当。形状填充不能替代明确的数据图例。

## D. 数据／信息架构

推荐的信息组织顺序：

**语料来源 → 词项提取 → 清洗与归并 → 频次／权重 → 视觉映射 → 词云版面 → 来源与方法注释**

建议在作品或附注中说明：
- 语料来源、时间范围与样本规模；
- 分词语言、停用词及词形归并规则；
- 采用词频还是其他权重；
- 字号、颜色和位置分别代表什么；
- 未显示词项的筛选阈值。

## E. 视觉叙事架构

词云通常先以整体形态和最大字号建立主题印象，再引导观者浏览次级词项与语义群组。若需要表达明确的主题关系，可增加分组、图例、注释或辅助说明；不要让装饰性轮廓掩盖词语之间真实的语义关系。

## 识别标准与误用风险

**识别标准**
- 以词项或短文本作为主要视觉单元；
- 词项通过字号、位置、颜色、方向或空间聚集形成整体布局；
- 若声称是统计词云，应能追溯语料、词频／权重及其视觉映射规则。

**常见误用**
- 把字号大直接解释为高频，却没有词频依据；
- 将装饰性文字拼贴称为统计词云；
- 未说明语料来源、清洗规则和统计范围；
- 让颜色看似代表类别，却没有图例或分组说明；
- 过度旋转、重叠或缩小文字，导致无法阅读；
- 将词语的空间邻近误解为语义关联或因果关系。
