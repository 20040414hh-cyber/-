# 数据字典

转录表来源为[固定版本参考案例](https://github.com/fengbaifan/Infographic-Style-Repository/tree/111a6b42c7f6da436a5ad1ab82b9a40557f365dc/02-信息图形类型案例/05-流程图型-Process/案例/CASE-0002-Our-Process-曲线流程信息图)。数值表以原记录使用，属于参考库转录与测量。

## 基础数据集.csv

数据行数为5，列数为3。

| 字段 | 含义与口径 |
| --- | --- |
| stage_id | 阶段ID |
| order_key | 布局推断的阶段次序 |
| stage_name | 图中阶段名称 |

## 流程关系.csv

数据行数为5，列数为5。

| 字段 | 含义与口径 |
| --- | --- |
| relation_id | 关系ID |
| source_stage_id | 起始阶段ID |
| target_stage_id | 目标阶段ID |
| relation_type | 主顺序或反馈关系 |
| evidence_level | 原参考表中的推断证据级别 |

## 视觉标记.csv

数据行数为6，列数为6。

| 字段 | 含义与口径 |
| --- | --- |
| marker_id | 视觉圆标ID |
| center_x_px | 中心横坐标，像素 |
| center_y_px | 中心纵坐标，像素 |
| width_px | 宽，像素 |
| height_px | 高，像素 |
| shape | 形状 |
