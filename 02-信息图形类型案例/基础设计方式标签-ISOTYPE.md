# 基础设计方式标签：ISOTYPE

标签名称：`ISOTYPE`。标签层级：**基础设计方式 / 跨类型视觉编码方法**。建立日期：2026-11-23。

## 定位与使用规则

按用户明确的分类要求，ISOTYPE 在本知识库中作为基础设计方式标签独立记录，**不列为第18种信息图形表现类型，也不新增一种数据逻辑**。它可与编年、编目等数据逻辑以及比较型、时间轴型、混合型等表现类型组合，说明作品怎样把信息转化为可读的图形。

ISOTYPE 也不只是配色、剪影外观或图标素材库。本标签关注数据到图形的转换、符号单位、比较排列、文字说明和读者理解的共同组织。

## 概念依据与边界

Isotype 全称为 International System of Typographic Picture Education。Isotype Revisited 将其介绍为以图画组织和传播信息的方法；数量表达的重要原则是重复同尺寸符号，而非放大符号。该项目也说明 Marie Neurath 的 transformation 工作涉及把原始数据组织成图画表达。[来源：Isotype Revisited](https://isotyperevisited.org/2012/08/introduction.php)。

Pia Pedersen 对 Marie Neurath 工作的研究提醒，不能把这套方法简化成排列小人图标。[来源：Behind Isotype Charts，2017](https://journals.uc.edu/index.php/vl/article/view/5935)。

以下标签判据和操作表是本知识库的设计研究规则，不宣称为历史原作的完整规范或认证标准。

## 标签判据

| 状态 | 何时记录 | 如何写明依据 |
| --- | --- | --- |
| 已确认使用 | 有可靠作者/机构说明或历史来源支持，且能对照作品 | 记录原始出处、图中位置与具体使用方式 |
| 方法借鉴 | 当代作品主动采用相关编码与信息转换方法，但无历史体系归属证据 | 写“ISOTYPE 方法借鉴”，逐条说明符号、单位、排列和注释 |
| 待核实 | 缩图看不清、图例缺失，或只能观察到相似外观 | 记录可见事实与缺失证据，不直接给肯定标签 |
| 不采用 | 只有装饰图标、普通剪影或孤立导视符号 | 描述实际用途，不因有小人或扁平图标就归入 ISOTYPE |

不以“出现重复图标”作为充分条件；非定量解释性表达也不因没有计数就自动排除，需核对来源及具体的信息组织方法。

## A. 数据逻辑

先独立判定编年、层级、编目、字母表或地理关系，再记录 ISOTYPE 方法。比如“编年 + 比较型表现 + ISOTYPE 方法借鉴”中，三个标签分别说明组织关系、呈现任务和编码方式，互不替代。

## B. 统计图形与计算

对采用重复单位的数量图，设实际数量为 Q、单个完整符号代表量为 u，则符号当量为 Q/u。必须说明 u 的单位、时间窗、分母和适用范围。

人工核算示例：甲地120人、乙地80人，若1个符号代表20人，则分别是6个与4个同尺寸符号。此例是教学构造，不是真实案例。若为125人，需明确处理余量的方式；可配精确数字或标注近似，不悄悄舍入，也不让部分符号的形状造成错误的面积理解。

比较同一指标时统一符号当量与尺度；若分面必须更换当量，显著标注，不能让读者直接按图标个数跨面比较。

## C. 视觉编码与设计表达

| 要素 | 设计决策 | 核验重点 |
| --- | --- | --- |
| 符号语义 | 用何种简化图形代表对象/类别 | 读者是否能识别；是否存在文化歧义或刻板印象 |
| 符号单位 | 一个完整符号表示什么、多少 | 数量与单位能否复核 |
| 同尺寸与重复 | 同指标使用一致尺度的重复单元 | 不用放大图标暗示更多数量 |
| 行列与分组 | 对齐、行距、列距、组间留白 | 是否方便计数、比较和识别层次 |
| 色彩 | 区分类别或突出主题 | 色义稳定；不只凭颜色承担全部区分 |
| 文字 | 标题、标签、数值、图例与来源 | 补足符号不能独立表达的指标和语境 |
| 图文节奏 | 图形与注释的阅读顺序 | 先看懂比较对象，再找到结论与依据 |

扁平、剪影、几何化可作为外观选择，但不是本标签的唯一判据。设计表达应让符号既有识别性，又保持计数、比例与比较的清楚。

## D. 数据与信息架构

基础表建议将对象、类别、数值、单位、时间、来源ID分列；图形方案另记符号ID、符号当量、排序、分组、颜色和余量处理。不要将“20人/图标”混入数值单元格。符号素材以资源ID关联，并核对使用许可；历史方法可研究，不代表原图标素材可任意转载。

## E. 视觉叙事

明确作品要解释的问题，再决定符号重复、空间排列、分组和注释。优先让读者看清“谁与谁比较、差多少、单位是什么”，随后通过高亮和文字解释重点。单靠整齐的重复单元不能证明结论成立。

## 与相邻概念区分

| 概念 | 本库中的角色 | 与本标签的关系 |
| --- | --- | --- |
| 表现类型 | 时间轴型、比较型、混合型等页面呈现分类 | 可叠加 ISOTYPE 方法，不以它替代主类型 |
| pictogram / 象形图标 | 传达对象或动作的符号资源 | 可作为材料，但使用图标不等于采用 ISOTYPE 方法 |
| ISO 标准符号 | 特定标准规定的符号 | 应单独核对标准与用途，不能混称 ISOTYPE |
| isometric / 轴测表现 | 空间绘图方式 | 与是否使用 ISOTYPE 分开记录 |
| 平面/照片等风格 | 外观和素材表达选择 | 属于另一记录层次，不决定是否具备该方法 |
