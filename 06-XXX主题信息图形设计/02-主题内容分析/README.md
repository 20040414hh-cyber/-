## 分层分析，允许多标签组合



| 层次 | 回答的问题 | 候选标签或记录方式 |

| --- | --- | --- |

| 数据逻辑 | 信息按什么关系组织？ | 编年、层级、编目、字母表、地理；可主次组合 |

| 叙事任务 | 希望读者理解什么？ | 比较、变化、组成、关系、分布、过程、检索等 |

| 表现类型 | 页面如何呈现内容？ | 文字/列表型、照片/图片型、时间轴型、混合型等；按 02 定义核对 |

| 图形与图表 | 哪种编码适合字段关系？ | 词云、地图、条形、矩阵、关系图等候选 |

| 视觉风格 | 用何种视觉语言表达？ | 平面风格、照片风格、插画、几何、手绘等候选 |

| 素材与媒介 | 能使用什么、在哪里阅读？ | 文本、摄影、图标、矢量图形；纸面/屏幕等 |



例如“编年为主 + 照片型表现 + 时间轴组织 + 照片与平面图形混合”可以同时成立。平面风格与照片风格不是数据逻辑；词云也不能替代主题分类。照片型的具体命名与原知识库的图片型说明对照后记录，避免同义标签不断增殖。
