# 6 视觉编码：偏重设计表达



状态：待设计。编码要能被读者解读，同时形成连贯的画面语言。



## 编码与表现决策表



| 设计要素 | 需作出的决定 | 信息对应与检查 |

| --- | --- | --- |

| 点 | 位置、形状、大小、密度 | 代表对象还是测量值？面积是否对应数值？ |

| 线 | 方向、粗细、虚实、连接与曲率 | 关系、路径或时间？装饰线不能暗示不存在的联系 |

| 面 | 面积、分区、纹理与留白 | 组成或分组？比例与边界是否有证据？ |

| 体 | 体积、透视、层次与空间 | 是真实三维数据还是表现手法？遮挡和透视是否误导数量？ |

| 色彩 | 主辅色、高亮、类别色、顺序/发散尺度 | 语义一致、对比清楚；缺失与零区分 |

| 字体与排印 | 字体、字号、字重、行距、字距、对齐 | 标题/导语/正文/标签/来源分级；检查中文和长标签 |

| 图像与图形 | 照片、插画、裁切、轮廓、纹理、比例 | 统一拍摄/处理逻辑；说明事实图像与示意图 |

| 统计图形 | 图表类型、坐标、尺度、图例与标注 | 对应实际字段和叙事任务；定量精度可复核 |

| 图形符号 | pictogram、ISOTYPE、必要时的ISO标准符号 | 明确每个符号含义与数量单位，避免借符号暗示未经授权的认证 |

| 版式与节奏 | 网格、分栏、留白、图文关系、视线移动 | 主次明确；支持05的阅读路径 |



用户提到的“ISO图形”在实际采用时需明确所指：ISO 标准符号、ISOTYPE 图画统计和 isometric 轴测表现是不同概念。使用哪个体系就在本文件记录依据；未确定前不混称。
