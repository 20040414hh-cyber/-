## 来源与存放



- [01-公用数据集](01-公用数据集)：公开统计、机构开放数据等，保留下载原件。

- [02-文本文献](02-文本文献)：文献、报告、访谈文本等；优先保留来源链接与合法可存的材料。

- [03-自建数据集](03-自建数据集)：调查、观察、测量、摄影或人工标注的原始记录。



以上是来源分类。图像或文字也可来自公开来源或自建采集；不要把“数据类型”和“来源类型”混同。原始材料不直接覆盖，清洗后的成果放到下一阶段。
