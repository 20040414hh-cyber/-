# 5 叙事框架搭建



状态：待策划。每个叙事单元必须绑定实际字段与证据。



## 从字段组合到叙事主题



| 字段组合（示意） | 可构成的信息 | 仍需明确 |

| --- | --- | --- |

| 名称 + 纬度 + 经度 | 地图上的地点信息 | 坐标系、定位精度、地图范围；地图不是自动生成的论点 |

| 地区名称 + GDP数值 + 单位 + 年份 | 某地某年GDP | 来源、现价/不变价等口径；跨地比较需一致 |

| 人物名称 + 日期 + 事件文本 | 人物事件时间序列 | 时间精度、来源与事件选择依据 |

| 对象名称 + 图像ID + 特征类别 | 对象视觉编目 | 摄影一致性、分类规则、资源许可 |



以上为方法例，不是本选题已确认的数据或结论。“名字+数值”只有补齐指标与语境才能形成明确的信息。
