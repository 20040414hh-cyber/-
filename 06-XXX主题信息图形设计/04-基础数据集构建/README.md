## 核心规则：一格一值，一列一个变量



先定义每行代表的对象或事件粒度。每一列保持一种字段含义，每个单元格只存一个原子值；同一列可在多行存放同类数据。允许名义、量化、图像和文本字段，但不能在一格混入多个独立指标、单位和备注。



- 名称、类别、时间、数值、单位、来源ID分列；“120亿元（2025）”拆为数值、单位、年份。

- GPS 拆成纬度、经度两列，坐标系另列或记入数据字典，不能把坐标对塞在同一单元格。

- 一格只放一个图像资源ID或路径，图像文件放在 [02-图像资源](02-图像资源)；多张图片用关联表逐行记录。

- 文本字段可以是一段完整文本，前提是它是本研究定义的单个文本对象；若分析词语/句子，另建逐词/逐句表并关联原文ID。

- 多标签、多人物、多地点用关联表分行存储，不在一格用顿号拼接多个值。

- 缺失不等于零；规定统一缺失表示，不把“未知”混进纯数值列。ID、邮编等通常按名义字段处理。
