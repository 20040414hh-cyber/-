# G12 良好形态原则-Prägnanz

简洁/良好形态原则 · Prägnanz / Good Gestalt



**工作定义**：在条件允许时，知觉倾向于形成较稳定、规则、组织良好的整体。



**概念层级**：上位组织思想。定义为基于文献的中文概括，不是逐字翻译。



**信息图形应用建议**：用清晰层次、有限编码和一致排列降低结构歧义。



**误用与边界**：不是“元素越少越好”，也不是删除必要信息的依据；不等同于对称。



**原创教学练习**：比较两套信息量相同、层次不同的排版，检验能否更准确复述主题，而非只问是否更简洁。 此为待实施练习，不是已完成实验或真实商业案例。



**依据**：[来源 P](https://palmerlab.berkeley.edu/pdf/PalmerBrooks&Nelson.pdf)。
