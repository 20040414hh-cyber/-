# G06 连接律-Connectedness

连接原则 · Element Connectedness



**工作定义**：被明确连接的元素倾向于被知觉为相关的整体。



**概念层级**：后续扩展的分组原则。定义为基于文献的中文概括，不是逐字翻译。



**信息图形应用建议**：以连接线表达关系，以引线关联注释和对象。



**误用与边界**：连线可暗示关系或方向，必须有依据；不把所有连接形式统称均匀连接。



**原创教学练习**：同一组节点先只靠近、再显式连接，记录关系判断；连线语义必须在图例中说明。 此为待实施练习，不是已完成实验或真实商业案例。



**依据**：[来源 P](https://palmerlab.berkeley.edu/pdf/PalmerBrooks&Nelson.pdf)。
