## 证据等级与边界

- **源码事实**：直接来自本快照代码、配置和调用关系；每篇末尾链接固定 SHA 的源文件。
- **设计解释**：根据接口行为解释其方法价值，不声称是作者原话。
- **设计建议**：用于本知识库的工作规则，尚未由本次运行实验验证。
- 图表算法主体来自 `@rawgraphs/rawgraphs-charts`、`@rawgraphs/rawgraphs-core` 等外部包。本研究核实应用的注册与调用，不冒充对外部算法逐行审计。
- 本次进行静态源码研究和知识库结构/链接校验；未安装运行 RAWGraphs，未检验全部图表的实际输出或性能。注册存在不等于所有数据输入都能成功绘制。
- 版本字段 `2.1.0` 来自 package.json，不代表当前正式发布标签；依赖中的 `^` 范围不等于实际安装版本。
