# 从 RAWGraphs 提炼可维护的信息可视化风格

研究快照：`48c3b2ee9ff412721a2c99c7bed38e734b3fa534`；2026-11-23。本篇把应用源码事实转成设计工作方法；方法建议不是 RAWGraphs 官方设计规范，也不代表用户个人风格已由案例验证。

## A. 数据逻辑：先说明关系

沿用 01 的编年、层级、编目、字母表、地理结构轴，先写出“观众应识别什么关系”，再挑图形。相同配色不能把层级图变成时间图；相同长表也可支持不同问题。RAWGraphs 的 chart.dimensions 约束说明“可映射”，不能替代研究者对关系本质的判断。

## B. 统计图形与计算：风格必须携带口径

源码将数据解析、映射、聚合、外观参数分开。由此建议每份风格记录都包含数据粒度、字段类型、宽长表处理、聚合和排序，而非只存 PNG。尤其要明确 count 和 sum 的区别、均值的分母与是否需要加权；这些不能从漂亮的图形上倒推。

可用同一小数据表核对聚合：甲两行数值 10、20，乙一行 15。sum 结果为甲 30/乙 15；mean 为甲 15/乙 15；count 为甲 2/乙 1。这三张图回答不同问题。此例为人工构造的核算例，不是上游样例或运行截图。

## C. 视觉编码：分清产品界面与输出风格

### 已核实的界面样式事实

| --- | --- | --- |
| body 背景 | #f5f8fa | 低饱和工作区承托图形 |
| primary / success | #4bc06a | 用统一动作色组织操作反馈 |
| warning / danger | #e7b332 / #d04949 | 警告与错误区别呈现 |
| primary-lighter | #defff0 | 卡片悬停/选中底色 |

这些值来自应用 SCSS 与组件布局，不是默认导出图形的统一色板或字体承诺。图表内部外观由相应图表实现和 visualOptions 决定，不能把按钮绿色当作所有数据的最佳颜色。中文字体回退效果需要实测，Inter 本身不保证覆盖全部中文字形。

### 颜色尺度与语义

事实：constants 定义 sequential、diverging、ordinal；色板标签包含 Blues/Greens/Reds、RdBu/BrBG/PiYG、Category10、Turbo discrete、Spectral discrete。标签清单不证明所有图都提供同一控件组合。

建议：无序类别用离散色，连续数量用顺序尺度，有真实参照点的偏差可用发散尺度。仅选发散色板并不能证明零点已正确居中，应核对 domain。固定“类别→颜色”对应，避免换数据后颜色变义；说明缺失值颜色并与零区分。高亮色留给叙事重点，非重点保留足够辨识度。

面积图形应检查数值到面积的映射；长度图形应检查共同基线；密度图形应注明平滑/分箱规则。颜色不能补救错误的面积、比例与分母。对比度、灰度和色觉差异检查属于本研究建议，本次未作自动可访问性认证。

## D. 数据与信息架构：把风格存成可复现记录

建议记录以下内容，作为本文件的实践字段；它们不是可直接导入 RAWGraphs 的 JSON schema：

| 字段组 | 必填信息 |
| --- | --- |
| 研究身份 | 标题、问题、来源、日期、数据授权 |
| 版本 | 应用 SHA、依赖实际版本、浏览器/环境 |
| 数据 | 行粒度、字段、单位、缺失值、时间窗 |
| 转换 | 筛选、去重、宽长表、聚合、排序、标准化 |
| 图形 | 图表标识、实际维度映射、关键参数 |
| 风格 | 类别色表、色域、参照点、字体、字号、线宽、背景、画布与图例 |
| 输出 | .rawgraphs、SVG、最终版输出的位置与后期编辑说明 |
| 验证 | 核算结果、异常输入、已知边界及未验证事项 |

复用时优先保存 .rawgraphs 和 SVG：前者保留生成状态，后者允许精修。后期文字标注、版式和字体替换单独记录；不要只保存一张不可逆图片后宣称已建立可复现风格。

## E. 视觉叙事架构：图表生成后仍需编辑

App 提供“加载→选图→映射→定制→导出”五步工作流。设计解释：它组织制作过程，不能自动生成信息图形的标题、论点、证据注释、图组比较和阅读节奏。SVG 作为中间成果，适合后续补充这些层次。

建议读者顺序：一句可被数据支持的标题→指标和范围→主图→关键标注→来源与方法。用高亮、位置和注释说明重点；若要比较多个图，统一尺度、颜色语义、画布与排序。图例必须说明颜色/面积/带宽的意义，而非仅列出名字。

## 三个实践配方（设计建议）

### 1. 分类比较：建立克制的定量基底

输入“类别/数值/单位”，先核对每类是否多行，再决定 sum 或 mean。首选条形检验差值，保持长度基线合理；默认中性色，重点对象单独强调。导出 SVG 后补充单位、时间、来源和结论。检查排序是否把索引顺序改造成了排名，数量是否同口径。

### 2. 层级组成：拓扑与数量分开验证

先列父子路径、叶节点权重，核对同名节点是否需要完整路径区分；树图用于看分叉，treemap/sunburst 用于看组成。内部节点和叶节点若同时携带总量，先确认是否重复统计。颜色可以统一顶层类别，避免每个叶节点都争夺注意力；检查最小区域标签与跨层面积误读。

### 3. 时间趋势：让读者看见真实变化

整理“日期/系列/数值/单位”为长表，确认日期 locale、时间间隔和缺失值。折线用于变化，日历热图用于日周期，bump 用于名次。不得把缺失默认为零，也不能把不等时间间隔画成等距后省略解释。跨图比较固定时间窗与量纲，注释异常节点的来源证据。
