# 01 编年型信息图形：概念定义



## 核心判据



信息单元的主关系由**时间位置、先后顺序、间隔、持续时长或时间过程**决定；改变时间字段或顺序就会改变作品要表达的核心含义。最小数据单元可以是事件、时期、时间点测量或持续过程。与纯粹的“时间轴型”版式不同，编年逻辑也可能用折线、日历热力图或地图动画表现。



### 定义适用范围与本次补充依据

本次结合用户提供的《编年型信息图形-概念定义.pdf》（文内版本v0.4.0，2026-11-24，共16页）补充说明。该PDF的版本号与本仓库文件分别维护，本文件由v0.2.0更新为v0.3.0。PDF中关于单链、通道和布局的论述作为待检验的工作解释，具体修正见下文。

编年型以时间关系作为主要信息组织依据。单线事件顺序图是基本形式之一，实际作品还可能组织同时事件、持续区间、多主体时间线与周期。分类时说明主导的时间关系、读者任务及辅助关系，而不是只看时间轴的外观。

课件“单向、不可逆、顺序排列”“单维为主，较少延伸数据”“线性为主，具高度可变性”分别提示时间组织、维度取舍与编码形式。“结构—护栏—实现”可用于整理设计决策，但三行措辞本身不足以证明所有作品都必须满足唯一后继或单通道等形式条件。

## A. 基本数据逻辑



- **基础模式**：`事件ID | 实体ID | 开始时间 | 结束时间(可空) | 事件类型 | 数值(可空) | 时间精度 | 证据来源`。时间点是 `start=end` 的特例，但显示为瞬时事件；事件间可以有并行与嵌套。

- **关系本质**：`before/after`、`overlap`、`duration`、`same-period`、`change-over-time`。先后顺序是序数关系，时长是可度量差值，不得混淆。

- **尺度问题**：年/月/日/时应统一或显式转换；年代不确定的记录需要区间或“约”标识。离散序列与连续时间测量须分开。

- **必要区分**：时间先后不自动证明因果；多个事件并列不代表同权重。没有明确时间字段的步骤清单不必然属于编年型。



### A.1 单线序列的形式化范围

当有限事件集E中的事件具有明确且互异的先后关系时，可用严格全序≺描述。要求非自反、传递，并且任意两个不同事件都可比较先后。对于固定事件数n，其次序结构同构于1至n的自然顺序。

须区分完整先后关系与相邻后继关系。例如A≺B、B≺C时，传递性还给出A≺C。完整关系图中A可连接多个更晚事件；只画相邻关系才得到A→B→C的链。因此“非末端事件只有一个直接后继”应限定于该全序的相邻关系图，不用完整先后关系的出度定义“单向”。

固定n下的结构同构不决定事件间隔、持续时间、画幅、视觉距离或读者表现。数学上最早和最晚事件存在，呈现时仍需分别检验端点与方向是否可辨。

### A.2 并发、区间与不确定时间

| 数据情形 | 应保留的时间关系 | 可采用的表达 |
| --- | --- | --- |
| 同日发生、未记录时刻 | 同一时间粒度内并发 | 同日事件组、并列节点或分道，说明组内排序规则 |
| 持续过程相互重叠 | 开始、结束及区间重叠 | 区间条、共用时间尺度的泳道 |
| 年代仅知大致范围 | 时间区间与不确定性 | 范围带、约数、置信说明；不增加未经证实的时间精度 |
| 多主体同时推进 | 各主体过程与跨主体时间对应 | 分道或分面，说明共用尺度与跨道比较规则 |
| 周期中多次发生 | 周期相位与绝对轮次 | 同时记录年份/轮次与月、季等相位，按任务选择周期或编年视图 |

若用t(a)<t(b)定义严格先后，同时间戳的不同事件之间没有严格先后。可按时间戳形成有序事件组，组内保留并发。区间数据须说明按开始、结束还是区间先后比较，不能将某一种排序默认为全部过程关系。

组织并购、版本分支、流程反馈等连线可能表达业务或依赖关系，时间位置同时表达发生时间。出现分叉、汇合时，先说明连线语义和主导任务，再判断编年、层级或复合组织关系。

### A.3 时间语义与版面顺序的辨识

“打乱顺序是否损失含义”适合作为初步提问。日期仍完整保留时，乱序表中的时间关系可能可以恢复；字母索引被打乱也会损失检索效率。因此还应检查时间字段是否真实存在、读者是否需要据此判断先后/时长/变化，以及图形是否可靠表达这些关系。

无日期的步骤清单应根据实际的阶段、依赖和过程语义判断。仅有排列次序不足以确认历史编年归属。

## B. 统计图形与计算方式



| 数据任务 | 可借用的统计图形 | 计算或约束 |

| --- | --- | --- |

| 事件发生时刻 | 时间轴、事件点图、rug plot | 统一时间基准、处理并发与同日记录 |

| 持续过程 | 区间条 / 甘特式条带 | `持续时间 = 结束 - 开始`，注意时间精度 |

| 数量变化 | 折线图、阶梯图、面积图 | 同口径测量；`增量 = 本期 - 上期`；`增长率 = 增量/上期`（上期为零不可直接计算） |

| 周期比较 | 日历热力图、分面小多图、箱线图 | 相同时间粒度、可比的分组与观察窗口 |

| 累积进程 | 累积曲线、堆叠时间系列 | 先确认累计增量是否非负，再检查单调性；堆叠项口径互斥且完整 |



统计方法可涉及时间分箱、移动平均、同比/环比、变化率、插值等；平滑或插值必须披露方法，不能把估计点伪装为实测。



### B.1 顺序、时长和发生频率

开始时刻、结束时刻与持续时间均涉及时间。时长作为两个时刻之差，与事件次序承担不同的分析任务；表述时分别说明数据属性、测量尺度、视觉通道及其用途。顺序与时长可以共同服务编年组织，具体作品应披露所承诺的时间精度与尺度。

若比较第k时段的事件发生频率，可使用λ_k=N_k/Δt_k，其中N_k为按同一规则收录的事件数，Δt_k为时段长度。必须记录筛选标准、记录覆盖范围、缺失情况与时间窗。版面节点的疏密只有在映射和收录条件明确时才可支持频率解释。

累计增量均非负时，累计值才必然单调不减。包含退款、冲销、净变化或历史修订时，应按指标定义解释下降。示意图中的事件数和排版距离不作为真实频率或因果证据。

## C. 视觉编码：点、线、面、体、符号、色彩



| 变量 | 推荐编码 | 风险控制 |

| --- | --- | --- |

| 点 | 用点表示事件发生时刻、里程碑、异常峰值 | 密集事件应避让或分组，不移动真实时间位置而不注明 |

| 线 | 时间轴、进程线、数值轨迹；线型区分事实/预测 | 不能因连线制造不存在的连续观测；必要时画断线 |

| 面 | 区间带表示持续时间；面积图表达总量/组成 | 面积与数量的关系需按比例，不用装饰面积误导 |

| 体 | 轴测或三维插画可强化事件场景 | 体积、透视不能替代精确的数值刻度 |

| 符号 | 同类事件用固定图标语法，附图例 | 图标应语义一致、避免象形尺寸暗示错误数值 |

| 色彩 | 对类别用离散色，对强度用有序色；重点时刻强调色 | 不仅依赖颜色区分；对比度、色盲可读性与打印适应性 |



**关键规则**：若是等距时间刻度，图上距离必须与真实时间差相符；若改用等距节点布局，应明确标为“事件顺序图（非按时间比例）”。



### C.1 多通道编码与视觉层级

“单维为主”可作为优先突出时间任务的设计取舍，不能直接转化为禁止第二视觉通道的普遍规则。可用位置表示时间、面积表示规模、颜色表示类别，并分别提供图例与精确数字。应检验时间轨迹是否易追踪、通道是否与属性匹配、是否存在遮挡和误配，以及读者能否完成预定任务。

几何编码、视觉显著性与叙事重要性应分别记录。若用圆面积表示数值v，采用A∝v、r∝√v；若将半径直接设为与v成正比，则面积随v的平方变化，会扩大几何面积差异。人的面积感知偏差需要另以证据讨论。若圆的大小只表示编辑强调，须说明其语义。

### C.2 表示、尺度、布局与页面组织

| 决策项 | 记录内容 | 检查重点 |
| --- | --- | --- |
| 时间关系 | 先后、并发、区间、周期、不确定性 | 是否保留真实关系及时间精度 |
| 时间尺度 | 顺序节点、连续时间、分段、断轴 | 哪种距离表示时间差，单位如何解释 |
| 路径表示 | 直线、蛇形、径向、螺旋等 | 顺序、方向、端点与交叉归属是否可辨 |
| 页面组织 | 单线、分道、分面、分段、缩放 | 跨区域比较是否共用尺度，阅读入口是否明确 |

直线上的等距节点也可能只承诺顺序。曲线则可将沿路径长度s与时间t保持线性关系s(t)=k(t−t₀)，从而保留沿路径的时间距离。弯曲形态的比较难度与度量是否保留分别评估。径向图还应说明时间对应角度、半径还是沿路径长度，跨轮次的比较方法也须明确。

几何交叉不直接改变事件先后，应核验交叉处有无跨越标记、标签或其他足够线索。周期或圆形布局应区分一次性事件顺序、周期相位及轮次。箭头、刻度和编号的使用由具体阅读任务决定。

### C.3 表达方案与使用条件

| 表达方法 | 优先解决的问题 | 实施前检查 |
| --- | --- | --- |
| 顺序节点与卡片 | 理解事件推进 | 明示非按时间比例，卡片文字与节点对应 |
| 比例时间轴与区间条 | 比较时刻和持续时间 | 单位、刻度、断轴和区间端点一致 |
| 折叠、螺旋等路径 | 适应画幅与阅读节奏 | 路径归属、方向和尺度足够明确 |
| 多主体分道 | 比较同时发生的过程 | 时间对齐，避免将道间位置误读为进度差 |
| 阶段带 | 概括时期特征并组织图文 | 划分依据、边界精度及事件选择标准可追溯 |

每屏节点数、阶段数量、文字角度、行距和图形容量由载体、标签长度、受众与任务检验，不设统一数值阈值。相关方法可结合[Gestalt实践](../05-Gestalt视觉组织原则/03-设计实践经验.md)进行对照记录。

## D. 数据 / 信息架构



1. **底层事实**：原始事件、时间点指标、元数据（来源、统计口径、精度）。

2. **关联层**：按实体与时间字段排序、去重；建立阶段、前后/并行及类别关系。

3. **分析层**：分期、聚合趋势、找转折点/异常点；每个推导标记方法。

4. **呈现层**：主时间线 + 重点事件卡片 + 对照量尺 + 注释/出处；辅助数据不抢主线。

5. **检索层**：多条并行时间线可按人物、地区、主题筛选；长序列应有导航锚点。



### D.1 事实、关系与解释的记录

事件事实记录实际发生内容及来源，时间关系记录先后/并发/重叠，业务关系另记组织继承、合并、依赖或反馈。分析解释注明提出者、依据和待核事项。原始字段、推断关系、版面坐标分别维护，并用事件ID关联。

阶段可根据制度变化、统计转折、事件性质、预设时间窗或叙事任务划分。说明采用何种规则、边界是否确定、相邻阶段能否比较。固定年份窗口也可用于趋势和频率分析。

## E. 视觉叙事架构



推荐组织：**背景时段 → 起始条件 → 阶段变化 → 转折/对照 → 结果与未解问题**。可用“从宏观年代到局部事件”的缩放讲述，也可让多条并行事件形成对照。首屏应说明时间跨度、对象和证据范围；结尾标注“相关”与“因果”之间的区别。



### E.1 阶段、转折与因果的证据条件

阶段带可形成图文层级并帮助定位事件，使用效果需结合任务与实际作品检验。若要由节点疏密解释变化，应先核对收录完整性、时段长度与时间映射。示意性的排版疏密仅支持表达方案讨论。

事件卡片可分别写明“发生内容”“已证实的后果”“研究者解释与依据”。时间先后、同阶段出现及可见连线均不足以独立证明因果。为补足叙事而加入转折或因果时，应先补证据，并允许保留不确定结论。

### E.2 面向读者的任务检验

- 先后任务：是否能找出指定事件及前后事件，是否把并发错误读成严格先后？
- 时间任务：是否能判断时长、间隔或重叠，是否把等距节点当成比例时间？
- 多变量任务：是否能同时追踪时间与规模/类别，通道之间是否出现误配？
- 叙事任务：能否复述主题、阶段与依据，是否将编辑强调当成数量或因果证据？

记录版本、受众、任务、主要改动、实际表现与适用边界。未实施测试时，将效果保留为设计假设。

## 辨识检查与常见误判



- 若删除时间字段，图的核心关系是否仍成立？若仍成立，可能只是采用时间轴外观的编目表。

- 时间间隔是否被等距节点替代？若是，必须披露布局的非等比例性质。

- 事件取舍是否服务叙事却牺牲完整性？应说明筛选标准，避免制造必然进程。
